# 小ONE会客厅

嘉宾单人出镜，小ONE在镜头外提问。技术标识是 `series: interview`。与房源、知识类共用正式发布编号，编号由 `npm run episodes` 计算。`purpose: test` 不占号。

新建：`npm run new -- interview <slug> --topic <主题>`。技术测试：`npm run new -- interview techtest --tech-test --topic 技术测试`。

流程见 `docs/RUNBOOK-interview.md`。各期素材和工作区独立，公共字体、品牌和 Node 依赖不按期复制。
