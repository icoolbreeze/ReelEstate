# voices/clone/ — 声音克隆参考音频（私有）

- 本目录除本说明和 `.gitkeep` 外全部被 gitignore，**不会提交**。
- 放置：参考音频 `*.wav`（建议 5–15 秒、干净无背景音）、对应逐字稿 `*.txt`，以及可选的 `qwen-codec` 预编码 `*.spk` / `*.rvq`。
- **必须有声音本人的单独书面授权**（《互联网信息服务深度合成管理规定》第14条），授权书扫描件放在这里或项目 `consent/`。
- 不得克隆明星、名人或未授权他人的声音。使用克隆声音发布时必须勾选 AI 标注。
- 克隆需要 BASE talker 模型（`qwen-talker-1.7b-base-Q8_0.gguf`，尚未下载），用法见 `docs/tts.md`。
