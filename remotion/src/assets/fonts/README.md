# 字体与许可证

全部为可免费商用字体，许可证文件放在各自目录中。`remotion/src/styles/fonts.ts` 用 FontFace 注册为 `RE ...` 家族名。

| 目录 | 字体 | 来源 | 许可 | 用途 |
|---|---|---|---|---|
| NotoSansSC/ | Noto Sans SC 可变字重（思源黑体同源） | https://github.com/google/fonts/tree/main/ofl/notosanssc | SIL OFL 1.1（OFL.txt） | 字幕、中文正文、地点标签 900 粗体 |
| AlimamaShuHeiTi/ | 阿里妈妈数黑体 Bold（官方 woff2 原文件，未修改） | https://fonts.alibabagroup.com | 阿里妈妈字体法律声明：个人/企业免费商用；**禁止修改、转换、二次分发为字体产品**（LICENSE.txt、INSTRUCTION.txt） | 房间卡中文、qiuzhi 标题 |
| Montserrat/ | Montserrat VF + Italic VF | https://github.com/google/fonts/tree/main/ofl/montserrat | SIL OFL 1.1 | mediastorm Latin 标题、房间卡英文 |
| BarlowCondensed/ | Barlow Condensed SemiBold/Bold Italic | https://github.com/google/fonts/tree/main/ofl/barlowcondensed | SIL OFL 1.1 | qiuzhi 英文/数字 |

- 数黑体不含 ㎡：面积写成 “m²” 用 Latin 字体排。
- 不使用方正、汉仪等商业字体；新增字体前先确认可商用，并把许可证放进目录。
