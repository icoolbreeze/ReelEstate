# 风格预设：mediastorm（影视飓风式）

> 数据来源：`ANALYSIS.pdf/docx`（参考片逐帧测量，原片 1920×1080，数值换算到 1440×1080）。
> 代码：`remotion/src/styles/mediastorm.ts`（tokens）+ `remotion/src/shots/*`（组件）。
> 这是“包装语言”，不是模板：每条视频的镜头顺序、钩子、BGM、选用哪几种卡片都必须不同（rules/style.md §5）。

## 1. 全局参数（写死在 tokens 里，改之前先改本文件）

| 项 | 值 |
|---|---|
| 响度 | 成片 **−16 LUFS**，真峰值 −1.5 dBTP（render.py 两遍 loudnorm） |
| 平均镜头时长 | **2.7–3.9 s**；单镜头 >5 s 必须有内部变化（推近、卡片二级信息） |
| 强调色 | **每条视频只用一种**：默认 lime `#D6EB00`；数据数字金 `#ECCE70`；超标/警示红 `#D60F28` |
| 调色 | 明亮、低饱和（`brightness 1.05 / saturate .82 / contrast .96`） |
| 推近 | 约 25–30% 的镜头做慢推（1.00→1.09），其余硬切静止 |
| 入场 | 文字卡**跟镜头一起硬切进来**，动画 4–12 帧，二级信息 +12–18 帧 |
| 字幕 | Noto Sans SC 600，42 px，白字细投影，底部 172 px；避开小窗与户型定位器 |
| 小窗 | 矩形 330×248，圆角 14，距边 140 px（参考片的机位角标比例） |
| 外部素材 | 左上角 `素材来源：xxx` 标签（SourceTag），AI 素材加 `AI生成` 角标 |

## 2. 卡片（组件 → 用法 → 测量值）

### 2.1 空间漫游房间卡 `RoomCard`（shot.room）
- 结构：`● ○ ○  ( MID FLOOR )` / `客厅 >> LIVING`，居中偏左。
- 中文：阿里妈妈数黑体，**斜体约 −11°**，字面高约 **180 px**；英文 Montserrat Bold Italic。
- 楼层胶囊高 **94 px**，圆点直径 **75 px**（间距 110）。楼层只写**粗略楼层**（LOW/MID/HIGH FLOOR），不写具体层数。
- 时间线（从硬切算起）：第 10 帧当前点 4 帧弹出 → 16–18 帧空心点 → **24–26 帧中文擦入** → 30 帧胶囊展开、英文逐字 1 字/帧 → 45–50 帧 `>> ENGLISH`；约 **1.5 s 建完**，在屏约 **3.3 s**。
- 配套 `FloorplanLocator`（shot.locator）：左下 **450×170**，当前房间填强调色；**必须标“户型示意 · 非比例”**。真实户型图（CRM floor_plan_url）只能按原图展示，不得“美化/重画”后当真实户型。

### 2.2 地点标签 `LocationLabel`（shot.location）
- 样式 `{ 示例地铁站 }`：粗黑体约 **165 px**，花括号约 **212 px**，右上红点 `#D60F28`。
- 动画：括号 12 帧 ease-out 展开，字从中间向两边逐个弹出，0.5–0.65 s 落定。
- **合规**：主标签只写地名；距离写在 `sub`，只能是“约 N 米 · 直线距离（来源）”，**禁止“步行 X 分钟 / X 分钟到地铁”**（rules/compliance/common.md）。距离必须来自 `map/pois.json` 的测距或用户提供的可核实来源。
  参考片的 `{ 地铁2号线 · 步行6分钟 }` 写法**不能照抄**。

### 2.3 规格卡 `SpecCard`（shot.spec）
- 左边距 **76 px**；Latin 标题 Montserrat SemiBold（字面约 95 px）；中文行 34 px 字面 / **59 px 行距**；白字 + 柔光。
- 8 帧淡入 + 整卡向右慢漂；各行从 **+18 帧**开始逐字打出。
- `variant: "warning"` = HEADS-UP 缺点卡（必须讲缺点，公约鼓励）。

### 2.4 数据数字 `DataNumber`（shot.number）
- 金色 `#ECCE70`，约 **110 px**；超出预算/限额时用红色（`over: true`）。
- 价格旁必须带“截至 YYYY-MM-DD”。

### 2.5 列表墙 `ListingWall`（shot 类型 wall）
- 4:3 网格 6–12 张卡：封面、小区、户型、面积、租金、朝向、粗略楼层；依次弹入 → 高亮选中卡（lime 描边 + PICK）→ 推近 → 切详情。
- 其他房源默认 `blur_others: true`（虚化），避免把别人的房源当自己的发布；要清晰展示就必须都有委托。
- 卡片不得出现 CRM 编号、平台 logo/水印、经纪人姓名。

### 2.6 地图推近 `MapReveal`（shot 类型 map）
- 卫星图 1.00→1.28 慢推，**图源署名常驻左下**（`map/geo.json.attribution`）。
- 公开发布的地图画面需要审图号或使用平台授权底图（待核实）；placeholder 示意图必须写“示意底图 · 非真实地图”。

## 3. 声音
- BGM 音量约为口播的 10%，whoosh 只在转场，点击声只在卡片弹出；全片 −16 LUFS。

## 4. 不要做
- 不要每个镜头都上卡片；不要多种强调色；不要花哨转场/抖动/粒子。
- 不要用 AI 生成房源实景、户型、景观、周边（flova 只能做装饰/转场，外加带“示意图 / AI 生成底图 / © 高德地图”标注的地图底图重绘）。
- 不要在卡片里写电话、微信、门牌、具体楼层、楼栋单元号。
- 动效由 `effects` 阶段按池抽取（`rules/effects/`）；mediastorm 不启用转场池，保持硬切。
