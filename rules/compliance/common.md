# 通用合规规则（所有分类）

> 整理自 `rules/reference/platform-rules-checklist.md` 与 `rules/reference/official-guidance.md`（2026-09-27 整理）。
> 不是法律意见；平台规则会更新，发布前以平台最新版本为准。标「二手来源」「待核实」的条目未读到官方原文。
> 机器可检查的部分由 `pipeline/check/check.py` 执行；其余靠发布前自检（`rules/workflow.md`）。

## 1. 视频号《房地产行业公约》（2026-05-07 修订，**2026-05-12 生效**）— 最高优先级

介绍具体房源/楼盘时，**视频内或标题中**必须写明（check.py 强制，InfoBar 常驻显示）：

| 必填 | project.json 字段 |
|---|---|
| 房产类型 | `property.property_type` |
| 建筑面积（或明确标注套内建筑面积） | `property.area.type` + `property.area.value` |
| 地址精确到街道或小区 | `property.location.street` / `property.location.community` |
| 真实价格 + 有效期 | `price.value` + `price.valid_until`（显示为“截至 YYYY-MM-DD”） |
| 中介机构全称 | `agency.full_name` |
| 期房：开发商全称 + 预售/销售许可证号 | `new_home.developer_full_name`、`new_home.presale_permit_no` |

其他要求：
- **兼顾优缺点**：`drawbacks` 不能为空（采光、噪音、楼龄、配套等）。
- **主要出镜人必须是视频号完成“生活服务-房地产中介服务”职业认证的本人**：`agent.certified_on_camera: true`。AI 数字人替代真人出镜在视频号房产内容上基本不可行。
- **禁止**：展示联系方式；“领取资料/获取底价”诱导；脚本雷同、模板化、表现形式高度一致的批量视频；矩阵霸屏；绝对化用语（“抄底”“定局”“全区最低价”）；承诺升值；把公寓包装成住宅；演绎“抢房”。
- 来源（官方文本·转载）：http://zhrealtor.com/newsDetail/9/11/975.html ；每经网 https://www.nbd.com.cn/articles/2026-05-09/4385189.html

## 2. 资质与房源真实性

- 抖音：发房源租售内容的账号需提交资质（企业号：营业执照 + 经纪机构备案；个人号：经纪人实名登记 + 在备案公司任职证明）。https://api.amemv.com/magic/eco/runtime/release/64f182f0c5dd2d057daeab3a
- 房源必须真实，经纪人实地查看、核对权属，**取得委托人书面同意**才能发布（《房地产经纪管理办法》第22、35条，罚款1–3万）。https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/201604/t20160426_776867.html
- 房源信息应通过房屋交易管理服务平台核验（建房规〔2023〕2号）。各地“房源核验码”具体要求 **待核实（查当地住建）**。https://www.gov.cn/gongbao/2023/issue_10566/202307/content_6890781.html
- 不得做广告的房源：被查封、无预售证的期房、权属有争议、违规建设等（《房地产广告发布规定》第5条）。https://www.gov.cn/gongbao/content/2021/content_5612986.htm
- 严禁捏造涨价信息、隐瞒真实交易信息、泄露委托人信息（《房地产经纪管理办法》第25条）。
- 地方要求示例：烟台要求账号首页公示机构备案号、经纪人资格管理号、实名登记编号（烟建住房〔2025〕15号，仅烟台，其他城市 **待核实**）。https://www.yantai.gov.cn/art/2025/8/13/art_58502_3298633.html

## 3. 广告用语（check.py 违禁词扫描）

| 禁止 | 依据 |
|---|---|
| 绝对化用语：最、第一、顶级、唯一、首选、国家级、最佳、全城最低 | 《广告法》第9条（罚20万–100万）http://www.npc.gov.cn/npc/c2/c12435/201905/t20190521_276667.html |
| 升值/保值/投资回报/稳涨/抄底/“买到就是赚到” | 《广告法》第26条；《房地产广告发布规定》第4条 |
| 用时间表示位置：“距地铁5分钟”“20分钟到市中心” → 改“距XX站约800米（地图测距）” | 《房地产广告发布规定》第4条第(二)项 |
| 面积不标口径（只写“89㎡”） | 同上第4条第(一)项 |
| 承诺户口、就业、升学、学区、学位、名校 | 同上第4条第(四)项、第18条 |
| 规划/在建配套不标“规划中/在建” | 同上第12条 |
| 效果图/样板间/AI画面不标“效果图/非实景” | 同上第13–15条 |
| 零首付、首付分期、首付贷、售后包租、返本销售 | 同上第16、17条；抖音房产规范（二手来源） |
| 风水、旺财、风水宝地 | 同上第8条；视频号运营规范 5.13.2 |
| 编造限时限量：“最后三天”“仅剩2套”“前100名” | 视频号常见违规 4.11.5 |
| “微信推荐/视频号推荐/平台认证好房” | 视频号常见违规 4.13.4 |

价格必须是真实实际价格并标有效期，不能用“示例”数字、诱饵价（第10条）。引用数据要注明出处和日期（第19、20条）。

## 4. 联系方式与导流（check.py 扫描）

- 画面、字幕、口播、封面、标题、角标、片尾都**不得出现**：电话号码、微信号、二维码、网址、店铺名、其他平台 logo，以及谐音/拆字/图片化变体（“V❤”）。
  - 视频号运营规范 5.20.2、4.7；常见违规 1.6、13.3、4.12.2/4.12.3、15.5：https://weixin.qq.com/cgi-bin/readtemplate?lang=zh_CN&s=video&t=weixin_agreement ；https://weixin.qq.com/cgi-bin/readtemplate?lang=zh_CN&s=video_guide&t=weixin_agreement
  - 视频号《商品推广内容创作方向及规则指南》6.1/6.2：https://support.weixin.qq.com/cgi-bin/mmsupportacctnodeweb-bin/pages/0XBk9tbwJME1GifU
  - 抖音社区自律公约：https://lf3-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/douyin_creator/40db1b96-0eb0-4754-a052-16e8325af350.html
- 不用“点赞/评论/私信领报价单”诱导互动；不在边框、角标持续展示 logo/品牌名。
- 合规留资：视频号挂留资组件或企业微信获客助手；抖音挂线索小程序锚点。CTA 写“点击下方组件预约看房”。
- 不得公布他人（业主、同事）联系方式或正脸照片。

## 5. AI 与标注

- 《人工智能生成合成内容标识办法》（2025-09-01 起施行）+ GB 45438-2025：AI 生成/合成内容发布时主动声明并用平台标识功能。https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm
- 抖音：发布页 → 高级设置 → 发文助手自主声明 → 内容由AI生成。视频号：发表页 → 添加标注 → 含AI生成内容。
- AI 配音/声音克隆：取得本人**单独书面同意**（《互联网信息服务深度合成管理规定》第14、17、18条）。https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm
- 不得 AI 仿冒明星/名人声音。AI 装修/补景画面同时算效果图：既标 AI，又标“效果图/非实景”。
- `project.json` 中 `ai_voice: true`（TTS 脚本自动设置）→ check 报告追加“发布时勾选 AI 标注”提醒，画面角标显示“含AI合成配音”。

## 6. 广告标识

- 替开发商/业主推广、收推广费、挂购买/留资入口的视频属于广告，需**显著标明“广告”**（《广告法》第14条；《互联网广告管理办法》第9条 https://www.gov.cn/zhengce/202305/content_6858084.htm ）。抖音商单走巨量星图。
- `project.json` 中 `ad_disclosure: true` → 画面角标显示“广告”。

## 7. 原创与质量

- 不搬运、不抄袭；只加边框/裁剪/镜像仍算搬运。同一素材只在一个账号发布（抖音《我们对原创的规则》https://trust.douyin.com/article/15179 ）。
- 视频号：只有照片+随拍+价格文案 = 违规低质（常见违规 4.12.1(4)）；画质模糊、黑边、轮播文字、大字覆盖、同模板只换房源价格 = 限流（运营规范 5.12、5.14）。
- 标题/描述/画面文字与内容一致，不做标题党。

## 8. 版权

- BGM 优先平台曲库；Mixkit 素材保留下载页截图和许可记录（许可条款二手来源，**待核实**）。
- Canva：付费素材只能在设计内使用；字体只能在 Canva 内或导出设计中使用；免费内容中的人物/商标/建筑不保证授权。
- 字体用 Noto Sans SC / 思源黑体（SIL OFL 1.1）；避免仅限个人使用的字体（如剪映部分字体）。

## 9. 画幅

- 4:3 在视频号 6:7–16:9 范围内不会被裁，但竖屏信息流中偏小；**4:3 画面内不得再加黑边/边框**。竖版投放优先 3:4 或 9:16。（推理结论，平台无 4:3 官方说明）
