# 新房（new-home）专项规则

> 先满足 `common.md`。本文件只列新房/期房额外要求。

## 必须（check.py 强制）

1. **开发企业全称**：`new_home.developer_full_name`。
2. **预售/销售许可证号**：`new_home.presale_permit_no`（期房广告须载明，只展示项目名称的除外 —《房地产广告发布规定》第7条；视频号公约同样要求）。**没有预售证的期房不得做广告**（第5条）。
3. **代理/销售机构全称**：`agency.full_name`（第7条要求载明代理机构名称）。
4. **效果图标注**：`new_home.renderings[]` 每项 `label` 须含“效果图”或“非实景”；样板间标“样板间”（第13–15条）。AI 生成画面同时标 AI。
5. **规划/在建配套**：`new_home.planned_facilities[]` 每项 `status` 必须是 `规划中` 或 `在建` 或 `已建成`，画面中未建成的必须标注（第12条）。
6. 价格：`price.type` 用“备案均价”/“参考均价”/“总价”等，写明有效期。

## 建议

- 贷款信息须写明贷款银行、额度、年限（第16条）；不宣传首付分期、售后包租、返本销售（第17条）。
- 不承诺升值、不说“买到就是赚到”；物业服务未实现的内容要注明（第19条）。
- 位置示意图比例准确（第11条）；交通用实际距离，不用“X分钟到”。
- 不得用其他项目图片冒充本项目（第14条）。
- 不演绎“抢房”“日光盘”场面，不编造“仅剩X套”。
- 开发商付费合作 → `ad_disclosure: true`，显著标“广告”。
