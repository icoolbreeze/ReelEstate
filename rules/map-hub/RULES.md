# map-hub 系列规则（地图主线口播）

基础口播规则见同目录 `mediastorm_koubo.md`（影视飓风量化版）。本文件只写 map-hub 的增量和取舍。

## 1. 结构
1. **开场**：multiplane 筛卡 → 扫描选中 → dolly zoom 进地图（`components/opener/Opener.tsx`，240 帧）。冷开场的钩子句压在开场上（L01–L02），不放结论。
2. **主持人**：开场后第一句给房源三要素（户型/面积/租金）（真实数据，只用 CRM/高德/开发商资料；仅当 sampleData=true 时才声明"示例数据"）。
3. **地图目录**（PIP）：一句话交代"点到哪讲到哪"，标记按"房间→小区→周边"逐类装配出现（assemble-then-type-flyin 的 shell 飞入）。这一句带 dialogue-duet：两枚具名光标（"你"/"主持人"）靠近、名牌一亮一暗交接，之后只留"主持人"光标。
4. **样板间**：地图上三张带照片的卡（客厅 / 卧室 / 厨卫）钉在房源针旁边。每张卡点一次进一组（2 条 B-roll），讲完缩回卡片。
5. **小区环境**：一个"小区环境（示意）"针，一次点击进 3 条（绿化 / 楼间距 / 出入口），口播里必须说明是 AI 示意画面。
6. **周边配套**：先主持人一句"距离都是高德实际路线距离"，然后地图逐个聚焦（地铁 → 学校 → 超市/商场 → 医院 → 公园），有实拍感素材的类别用点击进入 B-roll，其余在地图上讲（PIP）。
7. **收尾**：主持人总结 + CTA；频道名只在最后一句出现。

## 2. 光标与转场（input-trigger-moves A + collab-cursor-moves A）
- 光标走三次贝塞尔，f(点击−26) 起步，点击前 8 帧过冲到 t=1.05（甩腕），3 帧拐回；悬停的标记提亮（卡片描强调色边）。
- 点击帧：光标下沉 3 px，涟漪扩散（out-cubic 22 帧）与消散（线性 26 帧）解耦；地图层以点击点为原点 1→1.35 推近（12 帧）。光标、标记、地图在同一个缩放层，推近时点击点不漂。
- 段落从被点的标记"长出来"：矩形从标记框插值到全屏（点击+2 → 行起点+1，E_IO），圆角随之归零；结束时反向缩回标记，地图 1.35→1 退回（12 帧）。
- 点击进入的行前留 1.1 s 空拍（`gap`），点击在行起点前 12 帧（`CLICK_LEAD`）。全片点击 = 段落级开关，只用于"进入一个段落"，不用于翻页。
- 没有点击的地图行（PIP）：光标滑到正在讲的 POI 上悬停，不按下。

## 3. 段内标注（scanline-annotate-focus）
- 每条 B-roll 一次扫描：开场第 5 帧起 24 帧匀速扫完（零缓动），扫描线越过目标框**下缘**的那一帧弹框，最小间隔 3 帧；框 1.75→1 收拢（≤4% 过冲，7 帧），对焦闪 ≤0.07，标签晚 2 帧出现。
- 扫描线是浅色细线（白 0.85 + 柔光），不用黑线（用户否决过开场里的黑色下移横线）。
- 框弹出后**跟随跟踪数据**移动（`annotations/<ID>.json`），标签跟着框走；框上方没地方时标签收进框内上沿。
- 每条最多 4 个目标；标签 = 中文名 + 英文小字，序号用数据金 #ECCE70。右上状态行 `SCAN 0n/0N → ANALYSIS · COMPLETE`。
- 跟踪默认 LK 光流 + 相似变换（Muse 素材是慢推/慢移的静态场景，实测比 TrackerVit 准）；独立运动的物体再用 vit/csrt。

## 4. 地图
- 底图 `base_flovaSat3Db.png`（高德矢量插画底 + flova gpt-image-2.5 编辑 + 对齐 + 融合），平面投影见 `episode.json.plane`。
- 所有距离用高德路线距离（`pois.json`），画面写"步行 571 米 / 步行约 1.6 公里 / 驾车约 1.9 公里"；**不写步行时间**、不用"最/第一"、不承诺学区（学校行加脚注"入学以教育部门当年政策为准"）。
- 聚焦的 POI 画路线（医院画驾车路线，因为标签写的是驾车距离）；讲过的 POI 留名字小标签，路线降到 30%。
- 进入"周边配套"后样板间卡片和小区环境标签退场，避免压住近处的 POI。

## 5. 版式与合规
- 版式：`OPENER` / `A`（主持人全屏，硬切，第二个字幕块 1.18× 推近）/ `PIP`（地图 + 右下 330×248 主持人小窗）/ `B`（段落 B-roll）。
- 主持人全屏占比：本片 24%，低于口播规则的 35%，原因是地图段用 PIP 承担"人在讲图"。若要更像口播，把 L11/L16/L20 改成 A。
- 品牌条全片常驻（链家 / 德佑 / 富房 / CENTURY 21），浅色段纸色底，深色段（主持人、B-roll）暗色底白字；其他地方不出现贝壳 logo 和"房源信息来源"。
- 当前画面的来源说明（"示例数据"仅在 sampleData=true 时出现）（地图署名 / AI生成示意 非实拍 / 主持人画面为AI生成）。
- Muse 主持人片段有原声但没有对口型：成片只用 TTS，主持人画面静音。
