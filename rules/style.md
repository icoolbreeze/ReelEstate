# 视觉与讲解风格

> 定位：**科普/讲解型博主**，不是“房源轮播广告”。用户本人真人口播 + 信息卡 + 有设计感的镜头效果。

## 1. 结构（每条视频都要有，但顺序和比例每次要变）

1. **钩子（前 3 秒）**：先说价值点或问题（“预算 300 万在滨江，能买到什么样的两房？”），再点出房源。不编造稀缺性。
2. **信息卡**：房型、面积口径、价格+有效期、位置——用 Canva 设计的卡片（放 `canva/`）或 Remotion 动效卡片呈现。
3. **讲解主体**：户型动线、采光、配套（客观距离）、税费/贷款计算方法等“获得感”内容。
4. **需要注意**：明确讲缺点（`drawbacks`），这是视频号公约鼓励的。
5. **结尾**：总结适合人群 + 合规 CTA（“点击下方组件预约看房”），不放电话/二维码。

## 2. 真人出镜：全屏 ↔ 小窗切换（`presenter` 字段）

| 模式 | 用在什么时候 |
|---|---|
| `fullscreen` | 钩子、观点、总结、讲缺点（需要信任感的段落） |
| `pip-left` / `pip-right` | 展示户型图、实拍画面、信息卡、计算过程时；小窗放在不遮挡关键信息的一侧 |

- 小窗默认左下或右下，圆角 + 细描边，约占画面宽度 26%（竖版 34%）。
- 切换要有动机（内容变了才切），不要机械地每段都切。
- 主要出镜人必须是认证经纪人本人（公约要求）。

## 3. 字幕与信息条

- 全程字幕（视频号推广指南要求“必要的配音和字幕”），字体 Noto Sans SC / 思源黑体。
- **InfoBar 常驻**：房产类型｜建筑面积｜街道/小区｜价格（截至日期）｜中介全称。不要用巨大字覆盖整个画面（低质判定）。
- 角标（DisclaimerBadge）：示例数据 / 含AI合成配音 / 广告 / 效果图，按需自动出现。

## 4. 镜头效果（灵感来源：video-shotcraft）

参考 [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)（Apache-2.0；如直接移植代码须保留许可声明与出处）。可选效果：

- **2.5D crane-rise**：照片分层视差 + 镜头上升，用于小区/楼栋开场。
- **slam entrance**：标题/关键数字重击入场（配合音效，克制使用）。
- **light-leak cut**：漏光转场，用于段落切换。
- **split-flap price**：翻牌式价格（价格旁必须同时显示“截至日期”）。
- **tape / needle gauges**：卷尺、指针仪表展示面积、得房率、楼龄等数值。

每条视频挑 2–4 个，不要全部堆上。

## 5. 避免“模板感 / AI 感”

- 视频号公约**禁止脚本雷同、模板化、表现形式高度一致**的批量视频。每条视频至少变化：开场钩子类型、段落顺序、镜头效果组合、配色强调、BGM。
- 节奏按内容变：信息密集段放慢，展示段加快；不要固定每段 N 秒。
- 模板只统一“包装”（字体、InfoBar、角标），不统一“内容”。
- 避免 AI 生成的畸形人体、过度磨皮、塑料感渲染；实拍优先。
- 不加黑边、不加花哨边框、不做轮播文字墙。

## 6. 画幅

- 默认 4:3 横版 1440×1080（画面铺满，**不留黑边**）。
- 竖版 3:4（1080×1440）/ 9:16（1080×1920）：InfoBar 上移、PiP 放大、字幕区上移避开平台 UI。
