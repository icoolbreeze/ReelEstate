# 一句话成片：使用说明

> 给你（创作者）看的版本。Agent（Codex / Claude Code / OpenCode）都按 AGENTS.md 执行同一套流程。

## 1. 怎么用

对 Agent 说一句话即可，例如：

> 帮我做一条云栖苑两室整租的视频，4800 左右，影视飓风风格

Agent 会运行：

```
npm run make -- "帮我做一条云栖苑两室整租的视频，4800左右，影视飓风风格" --style mediastorm
```

风格固定为影视飓风 mediastorm，不需要你选。如果信息不够，它会先问你下面这些问题，再继续：

1. 这条是 **租赁 / 二手房 / 新房**？
2. **房源编号**，或小区名 + 户型/价格/面积/朝向；列表墙里**重点讲哪一套**？
3. 配音：**AI 配音**（需要你的书面授权）还是**你自己录**？
4. **业主委托/授权书**放进项目 `consent/` 了吗？
5. 必须公示的：二手房**核验码**、租赁**房源核验/登记备案编号**（按当地要求）、价格有效期、中介全称、出镜人是否认证本人。
6. **flova 生图**默认开启：MCP 已写在本仓库 `.mcp.json`，用于地图底图重绘（高德静态图 → flova 图像生成 → `map/base_ai.png` → 代码叠标签/距离）和装饰图；生图只用 GPT Image 2.5 Sunburst（成片/精修/品牌/地图重绘）或 Flare（日常/批量/社媒/试错），不生成户型/实景/景观/周边；积分由 flova 自己处理；想关掉再告诉我。**视频生成默认关闭**（`flova.video_allowed=false`），不生成任何视频（含地图动画），除非你明确要求开启。
7. 有没有要**排除的实勘照片**（有人像、门牌、水印等）？
8. 发**抖音**、**视频号**，还是都发？

## 2. 流程里发生了什么

| 步骤 | 做什么 | 生成的文件（在 projects/<分类>/<项目>/） |
|---|---|---|
| 0 解析 | 把你的一句话变成需求单 | brief.json |
| 1 取房源 | 从 CRM（只读）取房源、实勘图、户型图，只保留安全字段 | listing.json、raw/listing/ |
| 2 列表墙 | 6–12 套候选做成“房源墙”，高亮你选的那套 | wall.json |
| 3 地图（必选） | 高德静态图/卫星图 + 周边 POI 直线距离 + 路线数据；另由 Agent 用 flova 图像生成重绘底图（存 `map/base_ai.png`，退出码 3 等它），代码叠标签/距离；署名“示意图 / AI 生成底图 / © 高德地图”；不做视频动画 | map/ |
| 4 素材登记 | 每个素材登记来源、许可、是否有水印、是否 AI | assets/manifest.json |
| 5 脚本分镜 | Agent 按风格规则写口播和镜头表 | project.json、shots.json |
| 6 配音 | AI 配音或你的录音 | audio/ |
| 7 检查 | 合规 + 隐私 + 水印 + 地图署名，不通过就不渲染 | — |
| 8 渲染 | 1440×1080 成片，自动响度归一化（固定 −16 LUFS） | output/*.mp4 |

每一步都可以单独重跑，已有结果默认跳过。

## 3. 固定风格：影视飓风 mediastorm

明亮低饱和画面、一种强调色（荧光绿）、房间卡“客厅 >> LIVING”+ 左下户型定位、{ 地点 } 标签、左侧规格卡、金色数据数字、卫星图推近。镜头平均约 3 秒，镜头之间硬切，不使用转场特效。

## 4. 会被检查拦下的内容

- 电话、微信、二维码、网址、贝壳/链家等平台名称或 logo、CRM 房源编号/链接
- 人名 + 称谓、**具体楼层**（只能说低/中/高楼层）、楼栋/单元/室号、详细门牌地址
- “步行 X 分钟 / X 分钟到地铁”（只能写“约 N 米 · 直线距离”并说明来源）
- 素材清单缺项、带水印的素材、AI 素材用在户型/实景/景观/周边
- 地图没有图源署名
- 视频里没有地图/位置镜头（小区位置、通勤、周边配套；正式片直接拦下，示例片只提醒）

## 5. 你需要做的事

1. 租赁房源在云端 CRM。取数前看 `http://119.29.187.184:8080/archive` 是否在更新；本机执行 `ssh -N -L 8020:127.0.0.1:8020 beike-server` 后再跑成片。会话失效时由你在服务器上扫码，Agent 不代登。细节见 `docs/crm.md`。
2. 不要把本机 `BeikeMicroservice/services/crm_connector/run/` 里的旧登录态提交或同步。Agent 也不会去读它。
3. flova MCP 已写在本仓库 `.mcp.json`（Grok 读 `.grok/config.toml`），生图只用 GPT Image 2.5 Sunburst / Flare（按用途选），不生成户型/实景/景观/周边；视频生成默认关闭（`flova.video_allowed=false`），只有你明确开启才会用；不用再改你本机的客户端配置。
4. 每个项目把业主委托书、声音授权书放进 `consent/`。
5. 发布时：用了 AI 配音/画面要勾选 AI 标注；商单标“广告”。

## 6. 目前的限制

- CRM 实时取数和高德地图在本次样片里的验证情况见交付报告；样片使用虚构房源和图库照片，不是真实房源。
- 户型定位器目前是示意块图（“户型示意 · 非比例”），不是从真实户型图自动识别的。
- 竖版（3:4 / 9:16）目前是把 4:3 画面居中放入，会有上下留边，发竖版前需要单独适配。
- 兜底脚本比较模板化，正式出片必须让 Agent 按风格规则重写。
