## 规则（写稿 + 合成）
1. **不要碎句、不要戏剧停顿。** 分句 8–17 字；禁止“月租，四千八！”这种 2–3 字切碎；禁用“——”长停。
2. **停顿短而均匀**：逗号 0.22–0.30 s，句号 0.32–0.40 s，单段内最长不超过 0.45 s。
3. **语速 6.5–7.5 字/秒**，靠分句间轻微变速制造节奏：铺垫/连接句快（≈8 字/秒，F5 speed 1.10），关键数字/结论句慢（≈5.5 字/秒，speed 0.95）。整体不要大起大落。
4. **口语连接词开句**：“那……”“其实……”“但你会发现……”“所以……”，用来带过渡，读得轻快。
5. **句尾平稳轻落，不用感叹号**：结尾只降约 1 个半音，一半句子几乎平收；问句作为钩子（“能租到什么样的……？”）而不是喊。
6. 情绪来自内容和节奏，不靠音量/音高夸张：F0 范围大（±10 半音），但是在词重音上自然起伏，不是整句拔高。

## F5 落地方法
- 每句拆成分句，逐分句合成，每分句给 speed（1.10 过渡 / 1.05 叙述 / 0.95–1.0 关键信息）。
- 裁掉每段首尾静音，按规则 2 插入实测停顿，整句 −16 LUFS。
- 脚本：`projects/listing/ep07-xihu/voice/compare/ms_f5_script.json（ep07 测试期已删除，仅存档说明）`（分句 + speed），拼接参数见 box `/workspace/voice/ms/phrases.json`、`build.py`。

## 聊天感停顿规则（2026-10-12，phone ref 版）
用户反馈：要“像聊天”，不要念稿式的均匀停顿。
**禁止：IndexTTS 文本里不要用“——”。会被念出来（实测听成“减减”）。只用“，”或“……”。**

**首选：整段一次合成（IndexTTS-2.5，speaker = emotion ref = `assets/presenter/cool-breeze/voice/ref_phone_v1.wav`），用文字本身编码停顿，让模型自己处理韵律。**
- 口语化改写：事实不变，少量加入 嗯 / 你看 / 对 / 其实 / 然后 / 说白了 / 哈，一句最多一个，不要每句都加。
- 用标点编码停顿：
  - 逗号 = 思路内短停（约 0.15–0.3 s）
  - 句号 + 换行 = 思路之间（约 0.4–0.7 s）
  - 空行 = 换段/换场景（如“交通”→“客厅”）
  - “……” = 关键信息前的小悬念（约 0.9 s，实测 IndexTTS 往往只给 0.3–0.5 s）。每段最多 1–2 处。
- 关键数字/结论放在悬念后、单独成短句（“……都在这一站。”“……采光，就是这里的主角。”）。
- 出 2 个 seed，挑韵律最自然的；Whisper 检查漏字。

**备选（对照用）：按呼吸组分段合成再拼接**
- 组内停顿 0.15–0.3 s；组间 0.4–0.7 s；关键揭示前偶尔 0.9 s。不要等长，相邻停顿至少差 0.05 s。
- 每组 speed 在 0.92–1.08 之间轻微变化：连接词/铺垫快，关键信息慢。
- 拼接处 10–20 ms 交叉淡化，避免爆音；整段 −16 LUFS。
- 缺点：组与组之间语调不连贯，容易“一句一句念”。所以只作对照。
